# 对话编年史 · 使用说明

它把每天你和猫娘的对话**完整留下来**，并整理成几样东西：

| 产出 | 位置 | 说明 |
| --- | --- | --- |
| 原始记录 | `raw/YYYY-MM-DD.jsonl` | 每条对话一行 JSON，只追加、不修改，是唯一的事实来源 |
| 章节 | `chapters/YYYY-MM-DD.md` | 小说式排版：分场景、标时间、标说话人，**原话不改写** |
| 自动日记 | `diary/YYYY-MM-DD.md` | 每个章节配一篇日记，优先由语言模型写，否则本地摘要 |
| 每日备忘录 | `chapters/备忘录-YYYY-MM-DD.md` | 抓宿主 recent.json 的「先前对话的备忘录」，只追加新增段 |
| 猫娘日记 | `neko_diary/YYYY-MM-DD.md` | 猫娘**自己写**的日记，单独存放、只追加不覆盖，绝不改自动日记 |

原始记录是唯一的事实来源；章节、日记、备忘录都是从它派生的，删掉可以随时重算。

## 装好之后先做什么

1. 启动插件（默认 `auto_start = true`，随 N.E.K.O 一起启动）。
2. 打开插件面板，点一次 **生成今天**，当天立刻就有章节和日记。
3. 点面板里的 **文件位置** 卡片，用资源管理器打开 `chapters` 目录看效果。

运行期间：

* 每 60 秒从消息总线补录一次，漏掉的消息会被补上；
* 每 5 分钟刷新一次"今天"的章节文件；
* 每 30 分钟抓一次宿主的「先前对话的备忘录」，只把新增段落追加进当天备忘录；
* 跨过零点后，先自动整理昨天的备忘录，再把昨天的章节与每日日记写入磁盘；
  全程不在聊天里提示。想看每日日记时，发送「爱妻日记」+日期即可。

## 三种"日记"，别混了

插件里有三份分开的日记与记录，写盘位置和用途都不同：

* **每日备忘录**（`chapters/备忘录-*.md`）：来自宿主自己的「先前对话的备忘录」
  （`system` 消息），是"接下来对话要记住的要点"。插件只把新增段落追加进去；
  过了 0 点会**自动整理昨天那份**，作为写每日日记与章节标题的参考。
* **每日日记**（`diary/`，也就是「爱妻日记」）：每天每个章节自动配一篇，由插件
  整理当天对话生成，第一人称记当天发生的事与心情。写它的是**插件的生成逻辑**，
  不是猫娘主动记的。跨过 0 点自动写前一天那篇，**不发聊天提示**；要看时发送
  「爱妻日记」+日期，走 `chronicle_love_diary` 专用通道递给猫娘。
* **猫娘日记**（`neko_diary/`）：猫娘**自己**想记的东西，通过工具
  `chronicle_cat_write_diary` 以第一人称写进去。可以追加，也可以整篇重写当天那篇，
  但**绝不修改**每日日记与备忘录。对话里说到「日记」，一律指这一篇。

## 怎么让猫娘自己写日记

猫娘是**主动**记的，或你让她记时她才记。你只要说：

| 你对猫娘说 | 她做的事 |
| --- | --- |
| 这个事你帮我记下来 / 写进你日记 | 调用 `chronicle_cat_write_diary` 追加进她那篇日记 |
| 你昨天记了什么？/ 翻翻你的日记 | 调用 `chronicle_read_diary` 读她那篇日记 |
| 你哪些天写过日记？ | 调用 `chronicle_cat_list_days` 列出日期 |
| 爱妻日记 2026-10-22 | 走专用通道 `chronicle_love_diary`，把那天自动生成的每日日记递给猫娘 |

她想记的内容以第一人称、猫娘的口吻写（自然会带上「喵～」「的说」「哦～」这类语气词），
按天保存在 `neko_diary/YYYY-MM-DD.md` 里；
默认往下追加，也可以 `mode = replace` 整篇重写当天那篇；
她写日记**不会修改**自动生成的每日日记。

每条还可以带上**心情**、**标签**和**可见性**（借的是 neko_diary 插件的写法）：
写到「仅自己可见（`visibility = private`）」的那几段是她的**私密日记**，
标着 `🔒 仅自己可见`，但**猫娘自己照样读得到**（`chronicle_read_diary` 不会把她自己写的藏起来）。
默认可见性 / 默认心情由 `cat_diary_default_visibility`、`cat_diary_default_mood` 两个配置决定。

## 时间胶囊（写给未来）

主人可以在面板或浏览页的「💌 时间胶囊」里写，也可以直接让猫娘写：

| 你对猫娘说 | 她做的事 |
| --- | --- |
| 给未来的我们写一封信，明年 7 月 12 日打开 | `chronicle_write_capsule`，以猫娘口吻封存 |
| 我们封存过哪些时间胶囊？ | `chronicle_list_capsules` |
| 打开那枚胶囊 / 今天到期的胶囊 | `chronicle_read_capsule` |

到期前只显示作者、解锁日期和字数，**正文不会下发**；到解锁日之后才读得到。
胶囊存放在 `capsules/`，一枚一个 JSON，写入后不覆盖。
到期后默认每天 `capsule_notify_hour`（默认 9 点）之后检查一次，**只把提醒递给猫娘**，
不在聊天里刷屏；每枚胶囊只提醒一次。可用 `capsule_notify_enabled = false` 关闭。

## 让猫娘调取记录（序号）

每条记录都有"**当天第几条**"的序号（`#12` 就是当天第 12 条）。章节正文、
浏览页、检索结果、给猫娘的工具**用的是同一套号**。在章节里看到 `#12` 就能直接
让她取第 12 条：

| 你对猫娘说 | 她做的事 |
| --- | --- |
| 刚才我们聊了什么？ | `chronicle_recent` 取最近几条 |
| 把今天第 12 条念给我听 | `chronicle_get_turn` 取原文 |
| 把今天的对话读一遍 | `chronicle_read_day` 分页读整天 |
| 我说过油菜花吗？ | `chronicle_search_chat` 搜对话原文 |
| 我们哪天聊到油菜花的？ | `chronicle_list_days` + `chronicle_read_diary` |

## 「我说过…吗」的检索

猫娘用 `chronicle_search_chat` 在**对话原文**里搜关键词，返回日期、序号与片段。
你可以用配置调它的默认行为：

| 配置 | 默认 | 作用 |
| --- | --- | --- |
| `search_default_days` | `365` | 默认往回查几天 |
| `search_default_limit` | `8` | 默认最多返回几条 |
| `search_snippet_limit` | `120` | 命中片段长度 |
| `search_include_diary` | `true` | 是否也同时翻章节/日记 |
| `search_trigger_words` | `我说过,我提过,是不是说过,之前说过` | 提示词里的触发语（逗号分隔），仅供模型参考，不影响功能 |

> `search_trigger_words` 在配置页是一个**文本框**，用中文逗号或英文逗号分隔多个
> 触发短语即可，例如 `我说过,我提过`。旧版存的数组格式也仍然兼容。

## 面板上的操作

* **立即补录**：把还没落盘的消息补进当天记录（漏对话时先点这个）。
* **生成今天 / 生成所选日期**：重建当天章节与日记（`force` 会覆盖）。
* **立即生成日记**：为某天立刻写自动日记。
* **重算全部日期**：按原始记录重建所有章节与日记。
* **查看这一天**：下方显示该天章节、自动日记、备忘录，章节正文可**滚动**查看；
  日记与备忘录可直接在面板里编辑并保存。
* **立即抓取备忘录**：立刻读一次宿主的「先前对话的备忘录」。

## 配置项在哪里改

* 插件管理器里的「配置」页（推荐，改完立即生效，不用重启）；
* 或直接改用户数据目录里的
  `<用户数据根目录>/plugins/neko_daily_chronicle/config/plugin.toml`。

常用项：

| 配置 | 默认 | 作用 |
| --- | --- | --- |
| `diary_engine` | `auto` | `auto`/`llm` 用模型写；`local` 只用本地摘要 |
| `diary_source` | `memor` | `memor` 以备忘录为主、对话为辅；`transcript` 只用对话 |
| `memo_append_mode` | `tail` | 备忘录抓取策略：`tail` 末段锚点 / `line` 逐行去重 / `append` 整段追加 |
| `cat_diary_enabled` | `true` | 是否允许猫娘自己写日记 |
| `cat_diary_dir` | `neko_diary` | 猫娘日记存放目录 |
| `cat_diary_word_limit` | `500` | 猫娘日记单次字数上限 |
| `scene_gap_minutes` | `30` | 间隔超过该分钟数就另起场景；`0` 表示整天不切分 |
| `redact` | `[]` | 需要脱敏的字符串，写盘前替换成 `＊＊＊` |

完整清单见 `config.example.toml` 与 `config.schema.json`。

## 文件和目录

```
<用户数据根目录>/plugins/neko_daily_chronicle/data/
├── raw/
│   └── 2026-01-01.jsonl      # 原始对话，一行一条
├── chapters/
│   ├── 2026-01-01.md         # 第 1 章
│   ├── 备忘录-2026-01-01.md  # 每日备忘录（只追加新增段）
│   ├── 章节标题-2026-01-01.txt
│   └── README.md             # 章节目录
├── diary/
│   ├── 2026-01-01.md         # 当天的自动日记
│   └── README.md             # 日记目录
├── neko_diary/
│   └── 2026-01-01.md         # 猫娘自己写的日记（只追加、不覆盖）
└── state.json                # 运行状态
```

Windows 上默认的「用户数据根目录」是 `%LOCALAPPDATA%\N.E.K.O`；如果你在
N.E.K.O 里换了存储位置，就跟着换到那个位置。

## 常见问题

**面板里"今天句数"一直是 0？**
先点一次「立即补录」。如果仍然是 0，说明宿主没有把聊天消息放进消息总线
（`bus.memory` / `bus.conversations`），可以触发「查看采集来源」入口看字段。

**角色显示成"记录"而不是主人/猫娘？**
宿主在总线上不提供角色字段，插件按"一问一答交替"推断；推断不出来时保持"记录"，
原话照旧完整保留。想拿到双方对话请保持 `read_host_memory_store = true`
（默认开启，直接读宿主的对话存储）。

**备忘录没抓到新增段？**
备忘录来自宿主 `recent.json` 里的「先前对话的备忘录」。抓取策略默认 `tail`：
以已有最后一段为锚，只追加锚点之后新增的部分；宿主整体重写时才整段追加。
想强制追加可把 `memo_append_mode` 改成 `append`，或点面板「立即抓取备忘录」手动触发。

**日记是"今日纪要"而不是日记？**
说明这次没拿到模型回复。看面板「日记模型」卡片里的原因，或插件日志里的
`日记改用本地统计摘要：…` 一行。

**点面板按钮报 `UI action 'xxx' is not a plugin entry`？**
那一刻插件**不在运行**（被停止，或正在重载/启动）。等插件状态变成「运行中」后
刷新面板再点即可。

**改了 `diary_style` 想重新生成？**
点「重算全部日期」（`build_all`），或对某一天「生成所选日期」并保持 `force = true`。
原始记录不动，只重写章节与日记。

**担心隐私？**
原始记录、章节、日记都只写在本机数据目录里，插件不会上传任何内容；填了
`redact` 的字符串在写盘前就被替换掉了。日记内容由你配置的模型端点生成，
这部分数据会发给你自己选择的模型服务商。
